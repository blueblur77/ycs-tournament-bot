Privacy Policy

Last updated: 2026‑10‑26

What data is collected?

  • The bot reads a publicly available tournament page – no user‑generated data is accessed.
  • The bot stores the IDs of tournaments it has already announced in a local posted.json file.

How is data stored?

posted.json lives only on the host machine where you run the bot. It is never sent to any third‑party service.

Can you request deletion?

You can delete the file at any time, which removes all stored IDs.
